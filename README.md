# COVID-19 Information Website

Mini project 

## Features
- User registration and login (passwords hashed with bcrypt)
- Comment section for logged-in users
- Regular expression validation on client and server
- Test cases in `tests/test-cases.md`

## Tech Stack
HTML, CSS, JavaScript, Node.js, Express, MongoDB (Mongoose)

## Setup
1. Install Node.js and MongoDB
2. `npm install`
3. Start MongoDB, then run `node server.js`
4. Open http://localhost:3000
